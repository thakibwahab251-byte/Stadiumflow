# 🏟️ StadiumFlow

**StadiumFlow** is a real-time crowd dynamics and queue intelligence web application designed for large-scale sporting venues and arenas. Built for rapid deployment without complex databases or logins, StadiumFlow leverages **Google Gemini 3.8 Flash Vision** to perform zero-shot queue counting, physical bottleneck diagnosis, and automated fan rerouting.

---

## ⚡ Quickstart

### 1. Install Dependencies
```bash
python -m pip install -r requirements.txt
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and configure your Google Gemini API key:
```bash
GEMINI_API_KEY=your_gemini_api_key_here
PORT=5000
FLASK_DEBUG=True
```

### 3. Start the Web App
```bash
python app.py
```
Open your browser at: **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 🚀 Key Features

1. **Interactive SVG Arena Map**: Real-time visual concourse map with live congestion color thresholds (< 5m Green, 5–10m Amber, > 10m Crimson).
2. **Dynamic Bézier FastPath Connector**: Calculates and draws animated crowd diversion paths to nearby zero-wait facilities.
3. **Gemini 3.8 Flash Multimodal Vision**:
   - Zero-shot queue headcount estimation from CCTV or mobile photos.
   - Physical bottleneck diagnosis (stalled turnstiles, bag checks, slow POS).
   - Tactical marshal actions and attendee advice.
4. **Live Venue Dispatch Stream**: Real-time broadcast alerts and push notifications generated by Gemini.
5. **Living Venue Simulator**: In-memory Poisson simulation stepping crowd arrivals and service completions smoothly.
